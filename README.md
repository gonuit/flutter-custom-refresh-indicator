# Custom Refresh Indicator

[![Tests](https://github.com/gonuit/flutter-custom-refresh-indicator/actions/workflows/test.yml/badge.svg)](https://github.com/gonuit/flutter-custom-refresh-indicator/actions/workflows/test.yml)

Create your own custom refresh indicator widget in the blink of an eye!

### **[ONLINE DEMO](https://custom-refresh-indicator.klyta.it/#)**

## Packages

| Package | Description |
| - | - |
| [custom_refresh_indicator](packages/custom_refresh_indicator) | The _CustomRefreshIndicator_ widget, which makes it easy to implement a custom pull to refresh gesture. It does not depend on any design library. |
| [custom_refresh_indicator_material](packages/custom_refresh_indicator_material) | The _CustomMaterialIndicator_ widget, a Material Design indicator with a customizable content. |
